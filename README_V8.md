# Quick start
1. Termux: `bash tradebrain-ultimate-v8.sh` (same as before: pushes to GitHub, builds Pages + APK).
2. Open the app > Auto. Keep Execution = Paper. Pick a mode, tap Start scanning, tick "Place orders automatically".
3. Add an AI key in More > Connect for the AI Brain (policy Required needs it; choose Advisory/Off to run without).
4. Watch Home, Charts, Council, Positions. Export the journal from Positions.
5. Only after weeks of paper results: connect Binance **Testnet**, switch Execution to Binance, repeat. Live asks you to type LIVE.
