# v9 quick start
1. Connect tab: Deriv token and/or Binance key (choose Demo Trading for demo.binance.com keys). Saved keys reconnect on start.
2. Markets tab: tick the markets to watch (the list comes from the connected broker).
3. Overview: set your goal (start / target / deadline).
4. Auto: pick mode (NORMAL / A+ / MADBOT), execution (Paper first), AI policy. Tests tab shows how the rules did on recent candles.
5. Install the APK, allow notifications and Unrestricted battery so scanning continues in the background.
